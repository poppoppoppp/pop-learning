# Pop Learning

个人能力地图与项目驱动学习系统。

它记录的不是：

> 世界上有哪些技术知识。

而是：

> pop 当前真正理解和掌握了什么。

核心入口：

- `SYSTEM.md`
- `learner/CURRENT_STATE.md`
- `learner/ABILITY_MAP.md`
- `evidence/LEARNING_LOG.md`
- `concepts/DEPENDENCIES.md`
- `system/CHANGELOG.md`

Current Version:

`V1.2`

Started:

`2026-09-03`
